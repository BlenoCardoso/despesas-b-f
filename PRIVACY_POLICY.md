Política de Privacidade (Resumo - LGPD)

Última atualização: 2025-09-21

1. Dados que coletamos
- Informações da conta: nome, e-mail, id do usuário.
- Dados de household: membros, convites.
- Dados de uso e despesas: títulos, valores, categorias, datas, anexos.

2. Finalidade do tratamento
- Permitir o uso da aplicação (armazenamento de despesas, gestão de household).
- Sincronização entre dispositivos e membros do household.
- Geração de relatórios e exportação de dados (CSV/PDF) — apenas pelo próprio usuário.

3. Compartilhamento
- Dados de uma household são acessíveis apenas por membros dessa household.
- Não vendemos dados a terceiros.

4. Direitos do titular (LGPD)
- Acesso, correção, portabilidade, eliminação (quando aplicável), e revogação de consentimento.
- Para exercer direitos: entre em contato via o canal de suporte do app.

5. Segurança
- Dados são armazenados localmente no dispositivo (IndexedDB) e sincronizados conforme configuração.
- Medidas técnicas: controle de acesso por membership, validações no middleware, e comunicação segura quando aplicável.

6. Exportar / apagar dados
- Usuários podem exportar seus dados em CSV ou gerar versão em PDF via opção "Exportar meus dados".
- Para apagar conta/dados, o usuário deve usar a opção de exclusão no app ou contatar suporte.

7. Contato
- Para dúvidas ou solicitações de privacidade, contate o responsável do app.
